# Media Utility Desktop App

A CustomTkinter desktop app for practical media utilities.

## Current Feature

- PNG to JPG conversion
- Image compression for JPG, PNG, and WebP
- Output folder picker
- Quality slider
- Progress state
- Success and error popups
- Basic image preview information
- Before and after file size display for compression

## Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```
